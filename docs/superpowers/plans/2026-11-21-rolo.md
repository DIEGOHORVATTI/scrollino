# Rolo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App Android de rolagem automática para leitura, publicado na Play.

**Architecture:** Expo 57 (molde `~/Dev/FakeTraveler`), motor em módulo Kotlin
local `modules/scroll-engine` (AccessibilityService + botão em
`TYPE_ACCESSIBILITY_OVERLAY`), UI em Expo Router + NativeWind, estado em zustand.

**Tech Stack:** Expo 57, RN 0.86, NativeWind 5, zustand, AsyncStorage, oxlint, oxfmt, bun test, Kotlin.

**Spec:** `docs/superpowers/specs/2026-11-21-rolo-design.md`

## Global Constraints

- Pacote `com.diegohorvatti.rolo`, nome "Rolo", owner EAS `diegohorvatti`, minSdk 26.
- Velocidade 3–60 s/tela, padrão 15; atalhos 20/15/10; para após 60 min.
- `canRetrieveWindowContent="false"`, `isAccessibilityTool` falso, sem `SYSTEM_ALERT_WINDOW`, sem `INTERNET`.
- Código sem comentários; commits sem menção ao Claude.
- 21 locales iguais ao FakeTraveler; `bundles.test.ts` garante as chaves.
- Build nativo só no CI.

## Review Focus

- Usuário toca/arrasta a tela durante a rolagem → motor recua e retoma, sem dobrar a velocidade.
- Serviço desligado nas configurações com rolagem ativa → UI volta para "desativado" e botão some.
- App em primeiro plano fora da lista → pausa e retoma sozinho ao voltar.
- Tela apaga → para de injetar e solta o wake lock.
- Velocidade alterada pelo botão flutuante → tela inicial reflete o novo valor ao voltar.
